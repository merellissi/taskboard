1. Що змінилося у виводі git status після git add?
До git add файл index.html був червоним у списку Untracked files. Після git add index.html він став зеленим у розділі Changes to be committed, тобто потрапив в індекс, а інші файли залишились Untracked.

2. Що показує git diff?
git diff показує, чим робоча папка відрізняється від останнього збереженого стану: рядки з + додані, рядки з - видалені. Після додавання абзацу він показав рядок +    <p>TaskBoard допоможе керувати завданнями команди.</p>.

3. Чим відрізняється git switch main від git merge?
git switch main лише перемикає на гілку main і показує файли в її стані, нічого не об'єднуючи. git merge about-page переносить commit-и з іншої гілки в поточну, тобто об'єднує їхню історію.

4. Чому виник конфлікт і як ти його розв'язала?
Конфлікт виник, бо в гілках main і ukr-title по-різному змінено один і той самий рядок з h1, і Git не може сам вибрати правильний варіант. Я видалила службові рядки <<<<<<<, ======= і >>>>>>>, об'єднала обидва варіанти в <h1>Дошка завдань: керуй завданнями</h1>, виконала git add index.html і git commit.
